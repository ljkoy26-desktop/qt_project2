- 대상 파일: `spritesheetview.h`, `spritesheetview.cpp`, `mainwindow.cpp`

## 커밋 메시지 (예시)

```
qt_image_maker: 타일 순서 리스트를 스트립 미리보기 격자로 병합

- 우측에 별도로 있던 "타일 순서(드래그로 변경)" QListWidget을 없애고,
  상단 스트립 미리보기 자리로 옮겨 IconMode + Wrapping 격자로 재구성
  (선택/드래그 재정렬/우클릭 메뉴 5종을 그대로 재사용)
- QPainter로 매번 다시 그리던 정적 스트립 이미지(UpdateStripPreview) 제거
- "5/10/20개씩" 고정 개수 버튼 제거, 창 폭에 맞춰 한 줄에 보이는 개수가
  자동으로 조절되는 완전 반응형 격자로 변경 (QListView::Adjust + Wrapping)
- ▲▼ 버튼을 "이전으로"/"다음으로"로 라벨 변경 (동작은 기존과 동일,
  순서상 -1/+1칸 이동)
- "제외" 버튼 및 "선택 타일 확대" 패널은 기존과 동일하게 유지
- MainWindow 초기 창 높이 1100 -> 925로 축소 (1080 모니터에 맞춤)
```

## 변경 요약

1. `spritesheetview.h`
   - 제거: `m_pStripPreviewLabel`, `m_pStripScrollArea`, `m_pColumns5/10/20Button`, `m_nColumnsPerRow`, `OnColumnsButtonClicked()`, `UpdateStripPreview()`
   - `QScrollArea` 전방 선언 제거(더 이상 사용하지 않음)
   - 클래스 상단 설명 주석을 병합된 구조에 맞게 갱신

2. `spritesheetview.cpp`
   - 네임스페이스 상수를 `kGridIconEdge(64)`, `kGridSpacing(6)`로 단순화 (기존 `kGridCellSize/kGridNumberAreaHeight/kGridCellSpacing/kStripPreviewVisibleRowCount/kStripScrollAreaHeight` 제거)
   - `InitUi()`: `m_pListWidget`을 상단으로 이동, `setFlow(LeftToRight)` + `setWrapping(true)` + `setResizeMode(Adjust)`로 반응형 격자 구성. 아이콘 크기를 64x64로 확대. 우측 리스트 패널(`pRightPanel`)과 "5/10/20개씩" 버튼 관련 코드 전부 삭제
   - `m_pMoveUpButton`/`m_pMoveDownButton` 텍스트를 "이전으로"/"다음으로"로 변경, 툴팁도 "이전/다음 순서로 이동"으로 수정
   - 툴바 한 줄(제목 + 이전으로/다음으로/제외 버튼)을 격자 위에 배치, 그 아래 격자(stretch 1), 그 아래 "선택 타일 확대" 패널 순서로 재배치
   - `Populate()`/`AppendTiles()`/`Clear()`/`HandleReorderChanged()`에서 `UpdateStripPreview()` 호출 제거, `UpdateStripPreview()` 함수 정의 삭제
   - `Populate()`에서 매번 아이콘 크기를 20x20으로 재설정하던 중복 코드 제거 (`InitUi()`에서 한 번만 64x64로 설정)
   - 그 외 드래그 재정렬(`OnRowsMoved`), 컨텍스트 메뉴 5종(`OnListContextMenuRequested` 및 관련 슬롯), 제외 토글(`SetItemExcluded`), 번호 갱신(`RenumberItems`) 로직은 **변경 없이 그대로 재사용**

3. `mainwindow.cpp`
   - `resize(1450, 925)` (기존 1100에서 축소, 모니터 해상도 1080을 넘지 않도록)

## 검증 방법 및 결과

- `build` 디렉터리(CMake + Ninja + MSVC, Qt 6.6.3)에서 `cmake --build . --target qt_image_maker` 빌드 성공.
- `SpriteSheetView`를 직접 구동하는 임시 테스트 실행 파일(리포지토리 미포함, 스크래치 디렉터리에서만 빌드/실행 후 폐기)로 타일 60개를 채운 뒤 스크린샷 확인:
  - 창 폭 1450px: 한 줄에 18개씩 자동 배치, 우측 리스트 없이 격자 하나로 전체 기능(선택/번호/제외 버튼 활성화) 동작.
  - 창 폭을 950px로 줄이자 한 줄에 11개씩으로 자동 재배치됨(반응형 확인).
  - 툴바에 "이전으로 / 다음으로 / 제외" 버튼이 표시되고, "5/10/20개씩" 버튼은 존재하지 않음.
  - "선택 타일 확대" 패널이 격자 아래에 기존과 동일한 형태로 유지됨.

## 참고 (외부 호출부는 변경 없음)

`SpriteSheetView`의 공개 인터페이스(`Populate`, `AppendTiles`, `CurrentOrder`, `OrderChanged`)는 이번에도 변경하지 않았으므로 `mainwindow.cpp`의 호출부(`LoadImageFile`, `OnMergeFromFolder`, `OnSpriteOrderChanged`)는 창 크기 조정 한 줄을 제외하면 그대로입니다.
