## 커밋 메시지 (예시)

```
qt_image_maker: 스트립 미리보기 격자에 이미지 다중선택 지원

- QListWidget selectionMode를 SingleSelection -> ExtendedSelection으로 변경
  (Ctrl/Shift 클릭, 드래그 밴드 선택 가능)
- "이전으로"/"다음으로": 선택된 항목 전체를 그룹으로 묶어 한 칸씩 이동
  (연속/비연속 선택 모두 지원, 인접 스왑 반복 방식)
- 우클릭 메뉴 "맨앞으로"/"맨뒤로": 선택 항목 전체를 상대 순서 유지한 채 그룹 이동
- 우클릭 메뉴 "숫자를 입력하여 이동": 다중선택 시 비활성화(단일 선택 전용 유지)
- "제외/복귀" 버튼 및 메뉴: 선택 항목 상태가 섞여있으면 일괄 통일해서 토글
  (하나라도 포함 상태면 전체 제외로, 전체 제외 상태면 전체 복귀로)
- "해당 이미지 제거": 선택된 항목 전체 삭제, 확인 메시지에 개수 표시
- 우클릭 시 이미 선택된 항목이면 선택 유지, 선택 안 된 항목이면 단일 선택으로 전환
- 제외 버튼 상태 갱신을 currentItemChanged에서 itemSelectionChanged 기반의
  새 슬롯(OnSelectionChanged)으로 분리 (다중선택 그룹 상태를 정확히 반영)
- "선택 타일 확대" 패널은 기존과 동일하게 currentItem(마지막 클릭 타일) 기준 유지
```

## 변경 요약

1. `spritesheetview.h`
   - `MoveCurrentRow(int)` 제거, `MoveCurrentRowTo(int nTargetRow)`는 숫자이동 전용으로 유지
   - 추가: `OnSelectionChanged()`(slot), `SortedSelectedItems() const`, `SwapRows(int, int)`,
     `MoveSelectedRows(int nOffset)`, `MoveSelectedRowsToEdge(bool bToFront)`, `ApplyExcludeToggle()`

2. `spritesheetview.cpp`
   - `InitUi()`: `setSelectionMode(SingleSelection)` -> `ExtendedSelection`, `itemSelectionChanged` 시그널을
     새 슬롯 `OnSelectionChanged`에 연결
   - `SortedSelectedItems()`: 선택된 아이템을 row 오름차순으로 정렬해 반환하는 공용 헬퍼 신설
   - `SwapRows()`: 인접한 두 row의 아이템 위치를 `takeItem`/`insertItem`으로 교환하는 헬퍼 신설
   - `MoveSelectedRows(nOffset)`: 선택 row들을 이동 방향의 반대쪽부터 순서대로 `SwapRows` 반복 호출해
     그룹 전체를 한 칸 이동(연속/비연속 선택 모두 정확히 동작). 이동 후 선택 상태 재적용
   - `MoveSelectedRowsToEdge(bToFront)`: 선택 항목을 순서대로 꺼낸 뒤 맨 앞/뒤에 재삽입
   - `ApplyExcludeToggle()`: 선택 집합 기준으로 포함/제외 상태를 판정해 일괄 통일 토글, `OnSelectionChanged()` 직접 호출로 버튼 라벨 즉시 갱신
   - `OnListContextMenuRequested()`: 우클릭 항목이 이미 선택 상태면 선택 유지(다중선택 보존), 메뉴 라벨/활성화를
     선택 집합 기준으로 재계산, "숫자를 입력하여 이동"은 선택 1개일 때만 활성화
   - `OnRemoveItemClicked()`: 선택된 항목 전체를 row 내림차순으로 삭제, 확인 메시지에 개수 반영
   - `OnCurrentItemChanged()`: 확대 미리보기 갱신 역할만 남기고 제외 버튼 관련 코드 제거(중복 제거)
   - `OnSelectionChanged()`(신규): 선택 집합이 비면 제외 버튼 비활성화, 아니면 활성화 + 그룹 상태에 맞는 라벨 설정
   - 드래그 재정렬(`OnRowsMoved`), `CreateTileItem`/`BuildTileIcon`/`IsItemExcluded`/`SetItemExcluded`/
     `RenumberItems`/`HandleReorderChanged`/`Populate`/`AppendTiles`/`CurrentOrder`/`Clear`는 **변경 없이 그대로 재사용**

## 검증 방법 및 결과

- `build` 디렉터리(CMake + Ninja + MSVC, Qt 6.6.3)에서 `cmake --build . --target qt_image_maker` 빌드 성공
  (링크까지 정상 완료, 컴파일 오류 없음).
- `build\qt_image_maker.exe`를 실행해 3초간 프로세스 생존 확인(즉시 크래시 없음).
- **한계**: 이번 세션 도구 환경에는 네이티브 Win32/Qt GUI를 마우스로 조작하고 화면을 캡처하는
  자동화 수단(pyautogui 등)이 설치되어 있지 않아, Ctrl/Shift 클릭 다중선택 하이라이트, 그룹 이동,
  일괄 제외/복귀, 다중 삭제 등 실제 UI 동작은 자동으로 스크린샷 검증하지 못했습니다.
  로직은 코드 리뷰 및 수동 트레이싱(연속/비연속 선택 케이스 모두)으로 검증했으며,
  **사용자가 직접 실행해 최종 확인하는 것을 권장**합니다.
