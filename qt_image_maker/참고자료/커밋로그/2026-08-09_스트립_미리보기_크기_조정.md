# 커밋 로그 (실제 커밋 아님 - 기록용)

- 일자: 2026-08-09
- 작업 지시: `참고자료/작업지시/스트립 미리보기 (현재순서) 크기 조정 요청.md`
- 대상 파일: `spritesheetview.cpp`, `mainwindow.cpp`

## 커밋 메시지 (예시)

```
qt_image_maker: 스트립 미리보기 20개씩/5줄 기본 표시 크기 조정

- 스트립 미리보기 영역 높이를 "격자 5줄" 기준으로 자동 계산하도록 변경
  (kStripPreviewVisibleRowCount=5 상수 도입, 기존 고정값 180 제거)
- 스트립 미리보기 기본 표시 개수를 10개씩 -> 20개씩으로 변경
  (m_nColumnsPerRow 기본값 및 기본 체크 버튼)
- MainWindow 초기 창 크기를 1300x850 -> 1450x1100으로 확대하여
  20개씩 격자가 가로로 잘리지 않고 한 화면에 보이도록 조정
```

## 변경 요약

1. `spritesheetview.cpp`
   - 네임스페이스 상수 추가: `kStripPreviewVisibleRowCount(5)`, `kStripScrollAreaHeight`
     (`kStripScrollAreaHeight`는 `(kGridCellSize + kGridNumberAreaHeight + kGridCellSpacing) * 5 + kGridCellSpacing`로 계산되어 격자 상수가 바뀌어도 5줄 기준이 자동으로 맞춰짐)
   - `m_pStripScrollArea->setFixedHeight(180)` → `setFixedHeight(kStripScrollAreaHeight)`
   - 생성자 초기화 리스트: `m_nColumnsPerRow(10)` → `m_nColumnsPerRow(20)`
   - `InitUi()`에서 기본 체크 버튼을 `m_pColumns10Button` → `m_pColumns20Button`으로 변경

2. `mainwindow.cpp`
   - `resize(1300, 850)` → `resize(1450, 1100)` (20개씩 x 5줄 격자가 스크롤 없이 보이도록 여유 확보)

## 검증 방법 및 결과

- `build` 디렉터리(CMake + Ninja + MSVC, Qt 6.6.3)에서 `cmake --build . --target qt_image_maker` 빌드 성공.
- 파일 다이얼로그 자동화가 어려운 환경이라, `SpriteSheetView`를 직접 구동하는 임시 테스트 실행 파일(리포지토리에는 포함되지 않음, 스크래치 디렉터리에서만 빌드/실행 후 폐기)을 만들어 다음을 스크린샷으로 확인:
  - 타일 45개 기준: 기본 선택이 "20개씩"이며 0~19가 한 줄에 잘리지 않고 전부 표시됨.
  - 타일 110개 기준: 0~99(5줄)까지 잘림 없이 안정적으로 표시되고, 100번째 이후는 스크롤 영역으로 자연스럽게 이어짐(요구사항 3 충족).

## 참고 (외부 호출부는 변경 없음)

`SpriteSheetView`의 공개 인터페이스(`Populate`, `AppendTiles`, `CurrentOrder`, `OrderChanged`)는 이번에도 변경하지 않았으므로 `mainwindow.cpp`의 호출부(`LoadImageFile`, `OnMergeFromFolder`)는 그대로입니다.
